# IsoRim Waylith - Kiiro Pack

[Kiiro Race](https://steamcommunity.com/sharedfiles/filedetails/?id=2988200143) in the 3D view of [IsoRim Waylith](https://github.com/peren717/IsoRim-1.7) (RimWorld 1.7).

- Kiiro colonists are drawn as 3D figures in IsoRim's 3D view.
- Own body and head, with IsoRim's eyes.
- 3D hair styles, ahoge and cat ears; the ears take the skin colour and show above hats.
- A 3D tail that follows the body.
- Works with IsoRim's "Keep as paper" setting (Kiiro stays a 2D card when ticked there).

Requires IsoRim Waylith with Api 25 or newer and Kiiro Race (with Humanoid Alien Races and Ancot Library). Load after them. On an older IsoRim the pack does nothing.

XML and OBJ only, plus the shared `IsoRimPackGate.dll` from IsoRim (`Tools/PackGate`), which adds the patch only on IsoRim Api 25 or newer. The models are bound to Kiiro's addons by their texture paths.

**For modders:** this pack is a complete, working example of an IsoRim alien pack (`IsoRim.AlienModelDef`): no code, only the patch in `Patches/KiiroPack.xml` and the models in `Models/`. See IsoRim's Docs/ModelPacks.md ("Alien packs") and Docs/Api.md part 16.

Kiiro Race is made by Ancot. This pack contains no files of the original mod.

# IsoRim Waylith - Kiiro Pack（中文）

让 [Kiiro Race](https://steamcommunity.com/sharedfiles/filedetails/?id=2988200143) 在 [IsoRim Waylith](https://github.com/peren717/IsoRim-1.7)（RimWorld 1.7）的 3D 视角里显示为 3D。

- Kiiro 殖民者在 IsoRim 的 3D 视角里显示为 3D 小人。
- 专属的身体和头部，使用 IsoRim 的眼睛。
- 3D 发型、呆毛和猫耳；猫耳随肤色，戴帽子时露在帽子外面。
- 跟随身体的 3D 尾巴。
- 支持 IsoRim 的「保持纸片人」设置（勾选后 Kiiro 保持 2D 卡片）。

需要 Api 25 或更新的 IsoRim Waylith，以及 Kiiro Race（含 Humanoid Alien Races 和 Ancot Library），排在它们之后加载。IsoRim 版本较旧时本包不起作用。

只有 XML 和 OBJ，外加 IsoRim 共用的 `IsoRimPackGate.dll`（IsoRim 的 `Tools/PackGate`），只在 IsoRim Api 25 或更新时加入补丁。模型按 Kiiro 附加部件的贴图路径绑定。

**给模组作者：**本包是一个完整可用的 IsoRim 异种族包范例（`IsoRim.AlienModelDef`）：没有代码，只有 `Patches/KiiroPack.xml` 里的补丁和 `Models/` 里的模型。参见 IsoRim 的 Docs/ModelPacks.md（"Alien packs"）和 Docs/Api.md 第 16 部分。

Kiiro Race 由 Ancot 制作。本包不含原 mod 的任何文件。
